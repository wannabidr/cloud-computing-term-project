## + 모델 설정 명령 전체 정리

#### A. `openclaw models *` 전체 서브커맨드

| 명령 | 용도 |
|---|---|---|
| `models status` | 현재 모델/auth 상태 출력 |
| `models list` | 등록된 모델 목록 |
| `models set` | default 모델 변경 |
| `models set-image` | 이미지 모델 default 변경 |
| `models scan` | OpenRouter 무료 모델 자동 탐색 |
| `models aliases` | 모델 별칭 관리 |
| `models fallbacks` | 모델 실패 시 fallback 체인 |
| `models image-fallbacks` | 이미지 모델 fallback |
| `models auth *` | **인증 프로파일 관리** |

#### B. `openclaw models auth *` 세부 명령

| 명령 | 동작 방식 |
|---|---|---|
| `auth add` | 대화형 도우미 (질문에 답하며 등록) |
| `auth list` | 등록된 auth 프로파일 목록 보기 |
| `auth login` | provider OAuth 또는 API key flow |
| `auth login-github-copilot` | GitHub device flow |
| `auth order` | per-agent 우선순위 조정 |
| **`auth paste-api-key`** | **API key 직접 붙여넣기** |
| `auth paste-token` | OAuth/Bearer 토큰 붙여넣기 |
| `auth setup-token` | provider CLI로 토큰 생성/동기화 |

### 사용자별 셋업 가이드

```text
1. private key 파일을 ~/.ssh/openclaw_aaas_tnt_<이름>으로 저장
2. 권한 잠금:
   - Linux/macOS: chmod 600 ~/.ssh/openclaw_aaas_tnt_<이름>
   - Windows: icacls 으로 본인 계정만 R 권한
3. VM host key를 known_hosts에 등록:
   ssh-keyscan -t ed25519 <VM-IP> >> ~/.ssh/known_hosts
4. SSH 단독 검증:
   ssh -i ~/.ssh/openclaw_aaas_tnt_<이름> tnt_<이름>@<VM-IP> "whoami"
5. OpenClaw 설치 후 config snippet 머지
6. AI 모델 API key 등록
7. openclaw sandbox explain 으로 backend=ssh 확인
8. openclaw agent --message "..." 로 모델 페르소나 입력, 파일 생성 요청 등
```
